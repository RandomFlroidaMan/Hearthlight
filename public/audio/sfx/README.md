# Sound effects

Drop short one-shot sound effects here. Same extension rules as
`../ambient/README.md`: filename must exactly match a key below, any of
`.mp3`, `.m4a`, `.mp4`, `.wav`, `.flac`, `.ogg` (smaller/faster formats
preferred when more than one exists for the same key). A missing key just
plays nothing — no error.

| Filename            | When it plays                                          | Mood                                      |
| ------------------- | -------------------------------------------------------- | ------------------------------------------ |
| `choice-select.*`   | Tapping a choice on the story screen.                     | Light, quick tap/click.                    |
| `success.*`         | A skill check succeeds.                                   | Bright, small triumphant chime.            |
| `setback.*`         | A skill check fails — always a gentle, funny setback here, never harm. | Soft, a little silly — a "boop," not sad.  |
| `natural20.*`       | Rolling a natural 20.                                      | Bigger, more triumphant flourish.          |
| `item-reward.*`     | Earning a new item.                                        | Sparkly, delightful little jingle.         |

Keep these short (under ~2 seconds) — they play on top of narration and
ambience, not instead of them.
